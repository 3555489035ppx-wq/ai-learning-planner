# 3 分钟作品集演示脚本

| 时间 | 演示内容 |
|---|---|
| 00:00 | 学生的问题不是缺少任务，而是在补弱、目标与现实安排之间无法取舍。 |
| 00:20 | 输入高中数学 9/100、目标 60 分、六周、每天两小时。 |
| 00:45 | 展示低置信度诊断：成绩说明起点，但仍建议完成基础诊断。 |
| 01:05 | 展示学习阶段、Task Pool 和本周课表：阶段决定学什么，周课表决定什么时候学。 |
| 01:25 | 今日页展示下一件事、为什么现在做、完成标准和实际时长记录。 |
| 01:45 | 完成任务后展示 Evidence 与快速自检。 |
| 02:00 | 模拟旅行或延期，展示未完成任务回到 Task Pool。 |
| 02:15 | 展示 Recovery 方案差异、确认应用、ChangeSet 和撤销。 |
| 02:30 | 切换产品设计与计算机场景，说明课程内容、资源与进展按 `courseId` 隔离；如果面试官追问，再展开 1 对 1 辅导和真实导师接入边界。 |
| 03:00 | 总结：产品价值不是生成更多任务，而是解释取舍，并在计划被打断后帮助学习者继续前进。 |
