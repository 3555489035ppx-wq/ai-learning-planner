## 未审核检索建议

- 生成输入：稳定课程 ID、课程名称、教育阶段、省份、教材/课程大纲、知识点与当前基础。
- 每条包含：检索词、适用场景、看完后的练习、复制检索词和“去 B 站搜索”。
- 统一标记“未审核检索建议”，不会使用“精选”“播放最高”或“人工审核”等描述。
- 不包含虚构的视频 ID、标题、作者、具体视频链接或热度。
- 未知课程没有至少两个真实章节/模块时阻止生成；补充大纲后只使用用户上下文。

## Provider 边界

- `ResourceProvider` 定义远程接入接口。
- 当前 `mockResourceProvider.available === false`，明确返回空快照，不模拟后端。
- `validateResourceSnapshots()` 校验平台、视频 ID、标题、作者、检索词、状态、审核日期、统计类型和相关度。
- 第一版不在前端抓取 B 站、抖音或其他平台；真实视频搜索、健康检查和统计快照需要服务端 Provider 与平台许可。
