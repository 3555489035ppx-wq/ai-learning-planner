# 按钮与入口功能清单

| 页面 | 入口 / 操作 | 实际行为与持久化 |
|---|---|---|
| 首页 | 开始规划、继续今日计划、产品理念 | 跳转首次规划或今日；页内定位产品流程 |
| 首次规划 | 添加、编辑、删除课程；三步前后切换；生成诊断 | 校验课程事实、目标和现实安排；保存 v4 本地数据；并行生成分课程诊断 |
| 课程诊断 | 新版诊断、提交题目、预览计划、激活计划 | 分离考试/自评/表现/客观证据；生成有版本预览；确认后写入正式计划 |
| 今日 | 添加、开始、完成、编辑、延期、跳过、删除、更换资源、调整容量、自检 | 更新任务和事件；记录实际时长及原因；冲突校验；本地持久化 |
| 学习计划 | 周切换、拖动/移动、增删改、延期、跳过、完成、资源、旅行/时长调整 | 按日期与精确节次校验；先预览差异再应用；支持撤销 ChangeSet |
| 学习资源 | 筛选、原始来源、加入计划、不感兴趣、自有链接 | 外链打开原平台；要求课程/知识点/日期/节次/成果物；保存用户偏好与撤销 |
| 学习进展 | 课程切换、查看周复盘 | 从真实任务/测验事件计算，不用预计时长冒充实际时长 |
| 周复盘 | 保存回答、查看差异、应用下周计划、撤销 | 只调整目标周未完成任务；课程与周次锁防重复应用 |
| 设置 | 头像、名称、教育信息、课程目标、假期与 10 节课表、资源偏好、提醒、导入导出、清除、重新规划 | 所有字段和开关即时保存；导入校验 v3/v4；危险操作确认 |
| 全局 | 主导航、底部导航、学习教练、Toast 撤销 | 路由跳转；自然语言生成结构化调整预览；确认后应用并可撤销 |
| 法务 | 隐私说明、使用条款、返回设置 | 说明本地存储、未成年人、外部资源权利和成绩不保证 |
