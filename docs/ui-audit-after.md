# 假期跃迁发布前 UI 审查

审查日期：2026-07-17。范围：首页、首次规划、今日、课程诊断、学习计划、学习资源、学习进展、周复盘、设置、隐私与条款；桌面端 1440px 与移动端 390px。

## Hallmark

- 首页从通用 AI SaaS 话术收敛为“输入真实情况 → 找到优先问题 → 执行并调整”，AI 不再作为装饰标签。
- 今日页只突出下一件事；计划页使用真实 7 天 × 10 节课表；诊断页使用证据与阶段轨道；进展页使用“结果 → 证据 → 原因 → 调整”连续结构。
- 删除雷达图、排行榜、装饰图表、大蓝卡和重复等宽卡片墙。蓝色仅用于主行动、当前状态、焦点和链接。
- 中文标题字距、正文尺寸、卡片边界和按钮层级统一到 `design.md` 与 `tokens.css`。
- 复审结论：0 critical、0 major。未发现机器人、渐变光球、伪聊天框、假数据图表或重复 AI 标签。

## Web Design Guidelines

- 加入跳到主要内容链接、全局 `focus-visible`、非交互路由标题聚焦处理、44px 控件和 reduced-motion。
- Modal 支持 Escape、焦点循环、关闭后焦点恢复与背景滚动锁定；图标按钮均有可读名称。
- 首次规划按字段显示错误并聚焦首个无效字段；禁用提交按钮附带就近原因；异步按钮防重复提交。
- 所有核心路由的可见按钮/链接/表单控件均通过 Playwright 可访问名称检查，外链为空检查通过，浏览器控制台 0 error。
- 390px 下首页、今日、计划、设置均无页面级横向溢出；设置分类与内容已改为上下堆叠，可用内容宽度大于 300px。

## React Best Practices

- 非首页路由通过 `React.lazy` 与 `Suspense` 按需加载；生产主包由约 491 kB 降至 346.26 kB。
- 课程查找使用 memoized Map；多课程诊断并行生成；更新均通过函数式 store updater，避免陈旧闭包覆盖。
- 课程目录、4＋4＋2 时间表、诊断版本、计划版本、每日自检、任务与测验事件进入 v4 schema 和 v2/v3 迁移。
- 诊断、排程、课程智能、迁移、每日自检、变更集拆分为独立模块；Provider 保持可替换接口，本地实现明确标记。
