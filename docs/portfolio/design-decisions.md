# 设计决策

## 不把课表填满

4＋4＋2 是时间容器，不是每日十节任务配额。空 Slot 是缓冲，不是失败；短任务可以进入更长 Slot。

## 不把 backlog 当错误

本周放不下的任务保留在 Task Pool。用户看到的是“本周已安排 X 项，另有 Y 项将于下一周继续安排”，而不是开发者错误信息。

## 把解释放在行动附近

今日页和任务详情同时提供知识点、安排原因、完成标准、预计时长和证据边界。用户不需要打开调试面板理解计划。

## 先预览，再改变

计划调整、周复盘和恢复方案先展示影响，再由用户确认。每次确认产生可追踪 ChangeSet，并提供撤销路径。

## 安静而可感知的反馈

使用即时按压、明确焦点、短 Toast、对称 Dialog 进出和 reduced-motion 备选，而不使用装饰性动效。
