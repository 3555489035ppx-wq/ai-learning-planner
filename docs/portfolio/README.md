# 假期跃迁作品集导航

这是一个本地可运行的 React/Vite 作品集项目。以下文档共同构成产品、设计与工程证据链：

- [案例总览](./case-study.md)：适合首次阅读，说明问题、方案和结果边界。
- [产品叙事](./product-story.md)：解释为什么它不是待办清单。
- [三条用户旅程](./user-journeys.md)：高中数学、产品设计、计算机三类演示路径。
- [设计决策](./design-decisions.md)：信息层级、状态与可访问性原则。
- [工程说明](./engineering-notes.md)：数据模型、本地 provider 与可验证实现。
- [演示数据](./demo-data.md)：一键注入的场景说明。
- [演示脚本](./demo-script.md)：2–3 分钟录屏顺序。
- [限制](./limitations.md)：已实现、模拟与尚未验证的边界。
- [测试报告](./test-report.md)：执行命令、通过结果与截图证据。

截图输出到 `docs/screenshots/after/`。它们来自自动化视觉回归，不以硬编码成功状态取代真实交互。
