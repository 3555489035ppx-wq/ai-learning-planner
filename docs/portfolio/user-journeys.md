# 作品集演示旅程

## 场景 A：高中数学恢复旅程

输入高中数学 9/100、目标 60 分、六周、每天两小时。系统先显示低置信度成绩基线和约 15 分钟基础诊断建议；再生成基础建立、专项强化和综合应用阶段。任务进入 Task Pool，本周优先安排基础任务，其余工作保留到下一周。用户记录完成、延期或跳过原因后，系统基于 Evidence 生成恢复方案，用户确认后将未完成任务重新安排，并保留 ChangeSet 撤销入口。

## 场景 B：产品设计课程隔离

Photoshop、Illustrator、Rhino 分别使用图层与蒙版、路径与矢量、曲线与建模等独立上下文。任务以练习或作品产出为完成标准，资源绑定课程和知识点。页面与测试必须证明不出现数学或编程内容。

## 场景 C：计算机课程隔离

Python、数据结构、高等数学进入同一份总计划，但各自保留语法调试、数据结构与算法、函数极限等独立内容。资源、任务、Evidence 和进展均按 `courseId` 分离。
